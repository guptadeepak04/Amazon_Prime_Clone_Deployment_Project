# Project Overview
This project demonstrates deploying an Amazon Prime clone using a set of DevOps tools and practices. The primary tools include:

Terraform: Infrastructure as Code (IaC) tool to create AWS infrastructure such as EC2 instances and EKS clusters.
1. GitHub: Source code management.
2. Jenkins: CI/CD automation tool.
3. SonarQube: Code quality analysis and quality gate tool.
4. NPM: Build tool for NodeJS.
5. Aqua Trivy: Security vulnerability scanner.
6. Docker: Containerization tool to create images.
7. AWS ECR: Repository to store Docker images.
8. AWS EKS: Container management platform.
9. ArgoCD: Continuous deployment tool.
10. Prometheus & Grafana: Monitoring and alerting tools.
